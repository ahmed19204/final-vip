# VIP Center - منصة تعليمية

## 🎯 الوصف
منصة تعليمية متكاملة مع لوحة تحكم إدارية متقدمة، مصممة خصيصاً للكورسات والدروس الخصوصية.

## ✨ المزايا
- 🎥 إدارة الفيديوهات التعليمية
- 👨‍🏫 إدارة المدرسين والكورسات
- 🔐 نظام أكواد الوصول
- 📱 تصميم متجاوب
- 🌙 ثيم داكن أنيق
- 🇸🇦 دعم كامل للغة العربية

## 🛠️ التقنيات المستخدمة
- HTML5, CSS3, JavaScript
- Supabase (قاعدة بيانات)
- Quill.js (محرر النصوص)
- Cropper.js (قص الصور)

```
vip-center/

```

## 🚀 التثبيت والتشغيل

### المتطلبات
- متصفح حديث يدعم ES6+
- اتصال بالإنترنت (لـ Supabase)

### التشغيل المحلي
```bash
# تثبيت http-server
npm install -g http-server

# تشغيل الخادم المحلي
http-server -p 8000 -c-1 --cors

# فتح المتصفح
http://localhost:8000
```

### التشغيل على Vercel
1. رفع المشروع على GitHub
2. ربط GitHub بـ Vercel
3. النشر التلقائي

## 🔧 الإعداد

### بيانات الدخول الإدارية
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`

### إعداد Supabase
1. إنشاء مشروع في [Supabase](https://supabase.com)
2. نسخ Project URL و API Key
3. تحديث `supabase-config.js`
