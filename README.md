# VIP Center - منصة تعليمية متكاملة

## 🎯 نظرة عامة
منصة تعليمية متكاملة للثانوية العامة مع لوحة تحكم إدارية متقدمة، مصممة لتوفير تجربة تعليمية فريدة ومتميزة.

## ✨ المميزات الرئيسية

### 🎓 للطلاب
- **مشاهدة الفيديوهات التعليمية** باستخدام أكواد خاصة
- **تصفح الكورسات والتخصصات** المختلفة
- **التعرف على المدرسين** وخبراتهم
- **واجهة مستخدم بسيطة** وسهلة الاستخدام

### 👨‍💼 للمدرسين والإدارة
- **لوحة تحكم إدارية متكاملة** لإدارة المحتوى
- **إدارة المدرسين** والكورسات والتخصصات
- **نظام أكواد الوصول** للفيديوهات
- **إدارة الطلاب** والمستخدمين
- **رفع وإدارة الفيديوهات** بسهولة

## 🛠️ التقنيات المستخدمة

### Frontend
- **HTML5** - هيكل الصفحات
- **CSS3** - التصميم والأنيميشن
- **JavaScript (ES6+)** - التفاعل والوظائف
- **RTL Support** - دعم اللغة العربية

### Backend & Database
- **Supabase** - قاعدة بيانات PostgreSQL
- **Client-side Authentication** - نظام تسجيل الدخول
- **Real-time Updates** - تحديثات فورية

### Admin Panel
- **Quill.js** - محرر النصوص الغني
- **Cropper.js** - معالجة الصور
- **Responsive Design** - تصميم متجاوب

## 🚀 كيفية التشغيل

### المتطلبات
- متصفح ويب حديث
- اتصال بالإنترنت
- حساب على Supabase (اختياري)

### التشغيل المحلي
```bash
# تثبيت التبعيات
npm install

# تشغيل الخادم المحلي
npm start

# أو
npm run dev
```

### الوصول للموقع
- **الموقع الرئيسي**: `http://localhost:8000`
- **لوحة التحكم**: `http://localhost:8000/admin-login.html`
- **بيانات الدخول**: `admin` / `admin123`
